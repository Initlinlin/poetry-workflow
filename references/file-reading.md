# 文件读取说明

`prepare` 保存输入文件的提取文本快照，再按字符偏移分块。清单记录原文件 SHA256、快照 SHA256、字符数、每块起止位置及提取警告。`check` 将块重新拼接，与快照逐字校验；失败不能继续完整融合存档。

- TXT、MD：UTF-8（含 BOM）、UTF-16 BOM、GB18030；保留分行，不去掉 Markdown 正文，不把空行擅自当作新诗。
- EPUB：读取 spine 顺序文档，再读取未在 spine 中出现的 HTML/XHTML 文档，避免遗漏附录。导航、目录也保留供 AI 判别，不自动当作诗，可能出现重复目录；拒绝加密文件。
- DOCX：读取 word/document.xml 的段落文字。页眉页脚、批注、脚注、文本框和图片不是可靠的正文提取范围，输出明确提示；若它们属于选定范围，另行补齐后才能声称全部覆盖。
- PDF：需要 pypdf，逐页提取；空白提取页可能是扫描页或图片，应补充 OCR 文字或取得用户对纯文字范围的明确选择。阅读顺序、表格、页眉页脚需要核对。

保护性上限：单文件 50 MB，提取文字 800 万字符，压缩档展开总量 150 MB、档内单文件 40 MB、15000 个条目，PDF 最多 2000 页。超限明确失败，拆分后重试，不静默截断。字符预算不等于模型 token 预算。

清单、快照、阅读笔记属于用户资料，不提交到公开 Skill 仓库。阅读登记只是执行进度，不是语义理解正确性的证明。
